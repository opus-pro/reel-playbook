Hook

Stops the thumb in the first 3 seconds. The line, the first frame and the on-screen text all point at one question.

Rehooks

Every answered question is an exit. Close that one and open the next: "It held. But that was only rain."

Ending

Stops on the payoff with no outro or fade, so the replay feels like part of the video.
