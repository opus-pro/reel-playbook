Hey guys, quick fact! Fire hydrant cap colours follow the NFPA 291 flow classification system: light blue is 1,500 gallons per minute or more, green is 1,000 to 1,499, orange is 500 to 999, and red is under 500. This helps firefighters pick the right hydrant during an emergency. Pretty interesting, right? So now you know. Like and subscribe for more facts!
